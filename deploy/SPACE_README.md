# Iron Duel

1v1 top-down tank battles. Fight scripted bots, challenge **Neuron** (a PPO agent trained with
curriculum learning and self-play), get matched against another player, or watch agents duel.

**Controls:** WASD to move · mouse to aim · click or Space to fire · IJKL for keyboard aim.
